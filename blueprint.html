1. Executive Summary & Objective

Current robotic tactile data collection relies on expensive ($50k+) industrial arms that limit capture velocity and spatial diversity. This specification defines Project 1: Handheld Visuo-Tactile Collection Device—an open-source hardware and software platform enabling human operators to gather thousands of synchronized visuo-tactile manipulation trajectories per day in unconstrained real-world environments.

The system combines ergonomic 3D-printed parallel-jaw kinematics, dual GelSight-style camera-based optical tactile sensors, a 6-axis wrist Force/Torque sensor, wide-angle wrist cameras, and sub-millisecond ROS 2 hardware-timestamped stream logging into unified MCAP files.

4. Hardware CAD & Kinematic Design Requirements

Mechanical Architecture

  • Kinematics: Bimanual parallel-jaw slide driven by a spring-loaded index-finger trigger with constant-force mechanical feedback.
  • Stroke Length: 0 mm to 85 mm maximum parallel opening width.
  • Quick-Swap Finger Interface: Dovetail mount with locking thumb-screw allowing instant swapping between GelSight optical fingers, capacitive taxel pads, and rigid reference tips.
  • Rigidity: Structural parts printed in PETG or Carbon-Fiber Nylon (PA-CF) to eliminate flex under 50 N gripping loads.

GelSight Optical Finger Module

  • Gel Membrane: Clear silicone (Sorta-Clear 18) coated with an ultra-thin specular aluminum powder/silicone paint layer (~10–20 µm thickness).
  • Lighting Matrix: Directional RGB LED ring (Red at +X, Green at +Y, Blue at -X/-Y) cast at a 30° grazing angle relative to the gel surface.
  • Focus & FOV: Fixed-focus macro lens aligned to capture a 20 mm x 15 mm touch surface at 640x480 resolution @ 120 FPS.

5. Streaming Middleware & ROS 2 Architecture

The streaming stack runs on ROS 2 Humble. All sensor events are bound to a unified ROS 2 node that writes directly to an MCAP container via rosbag2_storage_mcap.

ROS 2 Topics & Message Definitions

# Topic Mapping
/tactile/left/image_raw      [sensor_msgs/msg/Image]             (120 Hz, GelSight RGB)
/tactile/right/image_raw     [sensor_msgs/msg/Image]             (120 Hz, GelSight RGB)
/wrist/image_raw            [sensor_msgs/msg/Image]             (60 Hz, Wide-Angle RGB)
/wrist/wrench               [geometry_msgs/msg/WrenchStamped]   (1000 Hz, 6-DoF F/T)

/pose/end_effector          [geometry_msgs/msg/PoseStamped]     (200 Hz, MoCap or SLAM Pose)
/system/sync_status         [diagnostic_msgs/msg/DiagnosticArray] (10 Hz, Clock Jitter)

from rclpy.node import Node
from sensor_msgs.msg import Image, JointState
from geometry_msgs.msg import WrenchStamped, PoseStamped
from cv_bridge import CvBridge
import cv2
import serial
import struct
import time

class VisuoTactilePublisher(Node):
    def __init__(self):
        super().__init__('visuo_tactile_publisher')
        
        # Publishers
        self.pub_left_gel = self.create_publisher(Image, '/tactile/left/image_raw', 10)
        self.pub_right_gel = self.create_publisher(Image, '/tactile/right/image_raw', 10)
        self.pub_wrench = self.create_publisher(WrenchStamped, '/wrist/wrench', 50)
        self.pub_gripper = self.create_publisher(JointState, '/gripper/state', 50)
        
        self.bridge = CvBridge()
        
        # Hardware Connections
        self.cap_left = cv2.VideoCapture(0) # Left GelSight Camera
        self.cap_right = cv2.VideoCapture(2) # Right GelSight Camera
        
        # Configure High-Speed Video Capture
        self.cap_left.set(cv2.CAP_PROP_FOURCC, cv2.VideoWriter_fourcc(*'MJPG'))
        self.cap_left.set(cv2.CAP_PROP_FRAME_WIDTH, 640)
        self.cap_left.set(cv2.CAP_PROP_FRAME_HEIGHT, 480)
        self.cap_left.set(cv2.CAP_PROP_FPS, 120)

        # Microcontroller Serial Interface for F/T Sensor and Encoder
        self.serial_port = serial.Serial('/dev/ttyACM0', 115200, timeout=0.001)
        
        # Timer Loops
        self.create_timer(1.0 / 120.0, self.publish_tactile_frames)
        self.create_timer(1.0 / 1000.0, self.poll_hardware_serial)

        self.get_logger().info("Visuo-Tactile Publisher Node initialized at high frequency.")

    def publish_tactile_frames(self):
        now = self.get_clock().now().to_msg()
        
        ret_l, frame_l = self.cap_left.read()
        ret_r, frame_r = self.cap_right.read()

        if ret_l:
            msg_l = self.bridge.cv2_to_imgmsg(frame_l, encoding='bgr8')
            msg_l.header.stamp = now
            msg_l.header.frame_id = 'left_gel_frame'
            self.pub_left_gel.publish(msg_l)

        if ret_r:
            msg_r = self.bridge.cv2_to_imgmsg(frame_r, encoding='bgr8')
            msg_r.header.stamp = now
            msg_r.header.frame_id = 'right_gel_frame'
            self.pub_right_gel.publish(msg_r)

Package the 6 force values and 1 angle value into a binary struct of 28 bytes (`<fffffff`) and stream it over USB CDC serial at 115200 baud with a 2-byte header `0xAA 0x55` for frame synchronization."

7. Hardware & Pipeline Verification Checklist

  • [ ] Thermal Validation: Ensure LED rings inside the optical gel fingers do not heat the gel past 45°C during 30-minute continuous capture sessions.
  • [ ] Optics & Focus: Verify sub-millimeter texture resolution by grasping a fine coin (e.g., U.S. Quarter) and confirming ridge lines are clearly visible in the gel image feed.
  • [ ] Timestamp Synchronization: Inspect generated MCAP files using Foxglove Studio to confirm image header stamps and F/T wrench stamps align within <1.0 ms.
  • [ ] Structural Deflection: Ensure the gripper jaws do not deflect by more than 0.5 mm at maximum 40 N pinching force.
